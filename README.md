# DompetRantau
Uang rantau, tercatat rapi.

Aplikasi web untuk mencatat dan menganalisis pengeluaran pribadi bagi
perantau (mahasiswa dan pekerja muda yang tinggal jauh dari rumah).
Proyek ini dibuat menggunakan AI Agent IBM Bob berdasarkan prompt
terstruktur tiga layer (Role & Context, Task & Requirement,
Constraint & Output).

## Fitur
- Input transaksi manual dan import CSV
- Saldo sekarang (tambah/kurangi saldo)
- Budget bulanan per kategori dengan progress bar
- Insight otomatis dan saran berhemat
- Grafik per kategori dan tren bulanan
- Tabel transaksi dengan edit, hapus, cari, filter, dan urut
- Export laporan ke CSV
- Dark mode

## Cara Menjalankan
Gunakan Live Server di VS Code, atau jalankan `npx serve .` lalu buka
alamat yang tampil di terminal.

## Teknologi
JavaScript (ES modules), Tailwind CSS (CDN), Chart.js, localStorage
